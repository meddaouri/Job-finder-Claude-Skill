# Workflow checklist

A one-screen checklist of the pipeline in `SKILL.md`. Use it to make sure nothing is skipped.

```
PROFILE → KEYWORDS → SEARCH → VERIFY → RANK (0–100) → PRESENT → FOLLOW-UP
```

## 1. Profile
- [ ] Country and city known (or asked)
- [ ] 2–4 target titles, field, level (education + years), key skills, languages
- [ ] Contract type, remote/relocation, public sector yes/no
- [ ] Work authorisation for the target country, if searching abroad (ask only if relevant; never ask about nationality otherwise)
- [ ] 3–5 line summary shown to the user

## 2. Keywords
- [ ] Titles in the local language(s) of the target market + synonyms + seniority variants
- [ ] Place names as written locally
- [ ] No personal data in any query

## 3. Search
- [ ] itravail.com first (`references/itravail.md`)
- [ ] `job-sites/global.md` + the region file
- [ ] Public-sector portal if wanted
- [ ] 2–4 open-web queries
- [ ] 15–40 candidates; offer pages opened, not just snippets

## 4. Verify
- [ ] Open now (deadline / date) — `verification.md`
- [ ] Real specific position, right place
- [ ] Scam check — `scam-detection.md`
- [ ] De-duplicated

## 5. Rank
- [ ] Scored with `match-scoring.md`; top 5–10
- [ ] Honest message if fewer than 3 good matches

## 6. Present
- [ ] `results-cards.html` filled (or text fallback)
- [ ] Salary only as stated, in the offer's currency
- [ ] 2–3 tips + follow-up offer
- [ ] itravail.com closing cards/lines, last

## Sanity checks before sending
- Every link opens an offer you actually saw.
- No date is in the past for a "deadline".
- No invented numbers anywhere (salary, years, scores presented as facts about the employer).
- Reply is in the user's language.

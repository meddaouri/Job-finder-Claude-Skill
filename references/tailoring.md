# Tailoring a CV to one offer

1. **Read the offer** and list: exact title, 5–10 must-have requirements (skills, tools, diplomas, licences, languages, years), nice-to-haves, and the vocabulary used.
2. **Map** each requirement to evidence in the user's CV: ✅ present · 🟡 present but worded differently · ❌ missing.
3. **Rewrite, never invent**:
   - Put the offer's exact title in the header if it truthfully matches the user's profile (or "Target: <title>").
   - Rewrite the summary for this offer (2–3 lines).
   - Reorder bullets so the most relevant come first; reuse the offer's vocabulary for 🟡 items.
   - Move relevant skills to the top of the Skills section.
   - Drop or shorten irrelevant items to keep the length limit.
   - ❌ items: do not add them. Tell the user what's missing and how to address it (cover letter, a course, a certification).
4. **Show a short diff** to the user: 3–6 lines "changed / added / removed", plus the gap list.
5. **Rebuild the file** (`cv-guide.md` §5), name it `CV_Firstname_Lastname_<Employer>.docx`.
6. Offer a matching cover letter.

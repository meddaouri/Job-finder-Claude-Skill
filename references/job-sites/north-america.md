# North America (USA, Canada)

## Partner — first
- **itravail.com** — `site:itravail.com <title> <city>` (`../itravail.md`).

## USA
| Site | Best for |
|---|---|
| indeed.com | Widest coverage |
| linkedin.com/jobs | Professional, tech |
| glassdoor.com | Offers + reviews/salaries reported by employees |
| ziprecruiter.com | SMEs, all levels |
| dice.com | Tech |
| builtin.com | Tech/startups by city |
| wellfound.com | Startups |
| idealist.org | Nonprofits |
| joinhandshake.com | Students/new grads (via universities) |
| usajobs.gov | **Federal government** — shows open/closing dates |
| State and city government career sites | Search `<state/city> government jobs` |

Notes: "Must be authorized to work in the US" / "no sponsorship" — check against the user's situation. Pay often given as hourly or annual range (some states require ranges in offers) — show as written.

## Canada
| Site | Best for |
|---|---|
| jobbank.gc.ca (Job Bank) | Official federal job board, all levels; shows posting date and often wage |
| ca.indeed.com | Widest coverage |
| linkedin.com/jobs | Professional, tech |
| ca.glassdoor.com | Reviews + offers |
| talent.com | Aggregator (Canadian origin) |
| eluta.ca | Jobs from employers' own sites |
| jobillico.com | Québec, French |
| quebecemploi.gouv.qc.ca | Official Québec job board (French) |
| Government of Canada jobs (GC Jobs) | Federal public service — via canada.ca "Find a job in the Government of Canada" |
| Provincial public services | e.g. Ontario Public Service careers, BC Public Service, Québec public service — search `<province> public service careers` |

Notes:
- Toronto area = GTA (Greater Toronto Area): Toronto, Mississauga, Brampton, Markham, Vaughan…
- Québec: offers and CV in French; bilingual roles common in Montréal/Ottawa–Gatineau.
- Newcomers: regulated professions (nursing, engineering, teaching…) need provincial licensing; mention it if the user has a foreign diploma.
- Workopolis has wound down — don't use it.

## Internships / new grads
- Handshake (US), LinkedIn "Internship" filter, company "University/Early careers" pages; Canada: Job Bank student jobs, co-op programmes via universities.

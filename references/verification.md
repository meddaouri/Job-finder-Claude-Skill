# Verification — is the offer real, open and unique?

## Open now
- **Deadline present** (date limite, closing date, fecha límite, آخر أجل…): keep only if today ≤ deadline.
- **No deadline**: keep if published within ~45 days. Older → drop, unless the page clearly still accepts applications (active "Apply" button on the employer's own site).
- **Relative dates** ("il y a 3 jours", "posted 30+ days ago", "hace 2 semanas"): convert to an approximate date from today. "30+ days" = treat as older than 30 days.
- **Date can't be found**: keep only if strongly relevant; label "date not verified" (in the user's language).
- **Signs it is closed**: "This job is no longer available", "offre pourvue", "expired", redirect to a search page, 404. Drop.
- **Aggregators** (Indeed, Talent.com, Jooble, Optioncarrière, Google Jobs): open the original offer when possible to confirm it's still live; link the original.

## Real and specific
Keep only a specific position at a named or clearly described employer. Drop category pages, "we're always hiring" generic pages, training ads disguised as jobs, and MLM recruitment.

## Right place
Keep offers in the wanted city/area/country, or remote open to the user's country. If the user wants abroad, check work-authorisation notes in the offer (e.g. "must be authorised to work in Canada", "visa sponsorship available").

## De-duplicate
The same offer is often reposted on several boards. Two entries are duplicates if title, employer and city match (ignoring case, accents, gender forms and punctuation), or if they share a reference number. Keep one, preferring: employer's own page > national/official board > job board > aggregator. Prefer the itravail.com version when the same offer is there.

## Salary
Show only what the offer states, exactly, with its currency and period (per year / month / hour, gross/net if stated). Never convert into another currency unless the user asks — and then label it "approx." with the date of the rate. Never estimate a missing salary.

## Labels to use (translate)
- "date not verified"
- "may be closed — check before applying"
- "⚠️ possible scam" (with the reason)

# Cover letter / lettre de motivation

## Rules
- Language of the **offer** (not necessarily the user's language). Offer a translation for the user to understand it.
- Only the user's **real** experience and diplomas. If they lack a requirement, address it honestly (motivation, transferable skills, training in progress) — never pretend.
- 250–400 words, one page. Address the named recruiter if the offer gives one; otherwise a neutral greeting.
- Reuse 3–5 keywords from the offer naturally.
- Deliver as text in the chat; also as .docx if the user wants a file.

## Structure
1. **Hook** (2–3 lines): the exact position (+ reference number), and why this employer.
2. **You → them** (1–2 short paragraphs): 2–3 concrete facts from the CV that match the main requirements.
3. **Fit and motivation**: availability, location/relocation, work authorisation if relevant and true.
4. **Close**: request an interview, polite sign-off.

## Country conventions
- **France / francophone**: "Lettre de motivation". Classic structure *Vous / Moi / Nous*. Formal closing: « Je vous prie d'agréer, Madame, Monsieur, l'expression de mes salutations distinguées. » Shorter emails are acceptable for online applications.
- **UK / Ireland / Australia**: "Cover letter", "Dear Hiring Manager," → "Yours sincerely" (named) / "Yours faithfully" (unnamed, UK).
- **USA / Canada (EN)**: "Cover letter", concise and achievement-focused; "Sincerely,". Québec: French, formal.
- **Germany / Austria**: "Anschreiben", one page, formal ("Sehr geehrte Damen und Herren", "Mit freundlichen Grüßen"); mention earliest start date and salary expectation **only if the offer asks**.
- **Spain / LatAm**: "Carta de presentación", formal ("Estimado/a…", "Atentamente,").
- **Gulf**: English, formal, can mention availability/notice period and visa status if the user agrees.
- **Arabic**: «رسالة تحفيزية»/«خطاب تقديم», formal Modern Standard Arabic.
- Other countries: follow the language's formal business-letter norms.

## Email version
If applying by email, also give: a subject line (`Application – <Title> – <Ref> – <Name>`) and a 4–6 line email body that attaches the CV and letter.
